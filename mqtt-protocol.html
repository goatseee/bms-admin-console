1. 概述

本协议定义了BMS（电池管理系统）设备端与管理平台之间的MQTT通信接口。设备端通过MQTT协议向平台上报电池实时数据、开关状态、电压信息、GPS定位、告警故障等信息；平台通过MQTT协议向设备下发控制指令，包括设备锁定/解锁、重启、休眠/唤醒、参数配置、故障消除、OTA升级等操作。

通信架构

┌─────────────┐     MQTT      ┌─────────────────┐     HTTP/WS    ┌──────────────┐
│  BMS设备端   │ ──────────→  │  MQTT Broker    │ ──────────→   │  管理平台后端  │
│ (硬件板子)   │ ←──────────  │  (消息中间件)    │ ←──────────   │  (BMS系统)    │
└─────────────┘   上行/下行    └─────────────────┘    订阅/推送    └──────────────┘

协议特点

  • 基于MQTT 3.1.1协议，支持QoS 0/1/2
  • 消息格式：JSON
  • 编码方式：UTF-8
  • 支持遗嘱消息（LWT）实现离线检测
  • 支持Retained Message实现设备状态保持

2. 连接规范

2.1 Broker连接参数

参数说明示例值
Broker地址MQTT服务器地址mqtt://broker.bms-system.com
TCP端口非加密连接端口1883
SSL/TLS端口加密连接端口（推荐）8883
WebSocket端口WebSocket连接端口8084
心跳间隔Keep Alive间隔（秒）60
连接超时连接超时时间（秒）15

2.2 Client ID规则

Client ID格式：bms_device_{IMEI}

示例：bms_device_864114070050327

注意：Client ID必须全局唯一，使用设备IMEI号确保唯一性。同一IMEI不允许同时建立多个连接。

2.3 认证方式

参数说明
用户名设备IMEI号
密码设备出厂时预置的Token（AES加密）

2.4 遗嘱消息（LWT）

设备连接时设置遗嘱消息，当设备异常断线时Broker自动发布离线通知：

参数值
LWT Topicbms/device/{imei}/status
LWT Payload{"imei":"{imei}","online":false,"timestamp":"{ISO8601时间}"}
LWT QoS1
LWT Retaintrue

2.5 QoS等级约定

消息类型QoS等级说明
心跳上报0允许丢失，高频消息
电池实时数据1至少一次，确保到达
告警/故障1至少一次，确保告警不丢失
设备注册1至少一次，确保注册成功
下行控制指令1至少一次，需设备确认
OTA升级指令2恰好一次，确保不重复执行

4. 公共数据结构

4.1 公共字段

所有上行消息的JSON Payload均包含以下公共字段：

字段类型必填说明
imeiString是设备IMEI号（15位数字）
msgIdString是消息唯一ID，UUID格式，用于消息去重
timestampString是消息时间，ISO 8601格式：yyyy-MM-ddTHH:mm:ssZ
msgTypeString是消息类型，见3.2节Topic清单中的type值

4.2 下行指令公共字段

字段类型必填说明
cmdIdString是指令唯一ID，UUID格式
actionString是指令动作类型
timestampString是下发时间，ISO 8601格式
paramsObject否指令参数，不同action有不同的参数
timeoutInteger否超时时间（秒），默认30

4.3 设备响应公共字段

设备收到下行指令后，需在 bms/device/{imei}/resp 上发布响应：

字段类型必填说明
cmdIdString是对应的指令ID
codeInteger是响应码，0=成功，非0=失败（见第7节）
messageString否响应描述
dataObject否返回数据（部分指令需要）
timestampString是响应时间

5. 上行消息（设备→平台）

5.1 设备注册 上行

Topic：bms/device/{imei}/register  |  QoS：1

设备首次上线或重新连接时发送注册消息，上报设备基础信息。

请求字段

字段类型必填说明
imeiString是设备IMEI号
imsiString是SIM卡IMSI号
deviceTypeString是设备型号，如 ZLB005D1507000_00
productTypeString是产品类型，如 家庭储能BMS、铅改锂储能BMS
batteryTypeString是电池类型，如 磷酸铁锂、三元锂
batteryStringsInteger是电池串数
hwVersionString是硬件版本号，如 AB3000X_H15S64Ah
swVersionString是软件版本号
sysVersionString是系统版本号
protocolVersionString是协议版本号，如 V1.0
msgIdString是消息唯一ID
timestampString是注册时间

示例

{
  "imei": "864114070050327",
  "imsi": "999010000000000",
  "deviceType": "ZLB005D1507000_00",
  "productType": "家庭储能BMS",
  "batteryType": "磷酸铁锂",
  "batteryStrings": 16,
  "hwVersion": "AB3000X_H15S64Ah",
  "swVersion": "ZLB005D-V2.3.1",
  "sysVersion": "F0-AB3000X-VR2025042",
  "protocolVersion": "V1.0",
  "msgId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "timestamp": "2026-09-18T08:30:00Z"
}

5.2 心跳上报 上行

Topic：bms/device/{imei}/heartbeat  |  QoS：0

设备定期发送心跳消息，上报基本状态。心跳间隔默认60秒，可通过平台配置修改。

请求字段

字段类型必填说明
imeiString是设备IMEI号
onlineBoolean是在线状态，固定为true
socFloat否当前SOC(%)，0-100
totalVoltageFloat否总电压(V)
currentFloat否电流(A)，正=充电，负=放电
deviceStatusString是设备状态：online/offline/working
timestampString是心跳时间

示例

{
  "imei": "864114070050327",
  "online": true,
  "soc": 85.5,
  "totalVoltage": 52.3,
  "current": 10.2,
  "deviceStatus": "working",
  "timestamp": "2026-09-18T08:31:00Z"
}

sohFloat是%电池健康度百分比，0-100
cycleCountInteger是次电池循环充放电次数
mosTempFloat是℃MOS管温度

protectionStatusInteger是-保护状态码，bit位定义见9.2节

dailyMileageInteger否米当天行驶里程（移动设备适用）

6. 下行消息（平台→设备）

6.1 设备锁定/解锁 下行

Topic：bms/device/{imei}/cmd/lock  |  QoS：1

平台下发设备锁定或解锁指令。锁定后设备停止充放电，解锁后恢复正常。

指令参数

字段类型必填说明
cmdIdString是指令唯一ID
actionString是固定值：lock
params.lockStateString是目标状态：locked（锁定）/ unlocked（解锁）
params.operatorString是操作人用户名
timestampString是下发时间
timeoutInteger否超时时间（秒），默认30

示例

{
  "cmdId": "cmd-20260918-lock-001",
  "action": "lock",
  "params": {
    "lockState": "locked",
    "operator": "admin"
  },
  "timestamp": "2026-09-18T10:00:00Z",
  "timeout": 30
}

设备响应

{
  "cmdId": "cmd-20260918-lock-001",
  "code": 0,
  "message": "设备已锁定",
  "data": { "lockState": "locked" },
  "timestamp": "2026-09-18T10:00:02Z"
}

6.2 设备重启 下行

Topic：bms/device/{imei}/cmd/restart  |  QoS：1

平台下发设备重启指令。设备收到后执行软重启，重启完成后自动重新连接并注册。

指令参数

字段类型必填说明
cmdIdString是指令唯一ID
actionString是固定值：restart
params.restartTypeString否重启类型：soft（软重启，默认）/ hard（硬重启）
timestampString是下发时间
timeoutInteger否超时时间（秒），默认60

示例

{
  "cmdId": "cmd-20260918-restart-001",
  "action": "restart",
  "params": { "restartType": "soft" },
  "timestamp": "2026-09-18T10:00:00Z",
  "timeout": 60
}
设备重启后无法立即响应，平台需等待设备重新上线注册后判定重启成功。超时后自动重连视为失败。

6.3 设备休眠/唤醒 下行

Topic：bms/device/{imei}/cmd/sleep  |  QoS：1

平台下发设备休眠或唤醒指令。休眠后设备进入低功耗模式，停止数据上报，仅维持心跳。

指令参数

字段类型必填说明
cmdIdString是指令唯一ID
actionString是固定值：sleep
params.modeString是目标模式：sleep（休眠）/ wake（唤醒）
params.sleepDurationInteger否休眠时长（秒），0=持续休眠直到唤醒，默认0
timestampString是下发时间

示例

{
  "cmdId": "cmd-20260918-sleep-001",
  "action": "sleep",
  "params": { "mode": "sleep", "sleepDuration": 0 },
  "timestamp": "2026-09-18T10:00:00Z"
}

6.4 GPS模块重启 下行

Topic：bms/device/{imei}/cmd/gps_restart  |  QoS：1

平台下发GPS模块重启指令。用于GPS定位异常时尝试恢复。

指令参数

字段类型必填说明
cmdIdString是指令唯一ID
actionString是固定值：gps_restart
timestampString是下发时间

示例

{
  "cmdId": "cmd-20260918-gps-001",
  "action": "gps_restart",
  "timestamp": "2026-09-18T10:00:00Z"
}

6.5 参数配置下发 下行

Topic：bms/device/{imei}/cmd/config  |  QoS：1

平台向设备下发参数配置，包括阈值参数、上报间隔等。设备收到后更新本地配置并返回当前配置快照。

指令参数

字段类型必填说明
cmdIdString是指令唯一ID
actionString是固定值：config
params.configsObject是配置项键值对，见下表
timestampString是下发时间

可配置参数项

配置项Key类型单位说明
cellOverVoltageThresholdIntegermV单体过压阈值
cellUnderVoltageThresholdIntegermV单体低压阈值
cellOverVoltageProtectIntegermV单体过压保护值
cellUnderVoltageProtectIntegermV单体低压保护值
voltageDiffThresholdIntegermV压差告警阈值
totalOverVoltageThresholdFloatV总电压过压阈值
batteryHighTempThresholdFloat℃电池高温告警阈值
batteryLowTempThresholdFloat℃电池低温告警阈值
mosHighTempThresholdFloat℃MOS高温告警阈值
chargerHighTempThresholdFloat℃充电机高温告警阈值
socLowAlarmThresholdFloat%SOC低电告警阈值
socLowProtectThresholdFloat%SOC极低保护阈值
sohLowAlarmThresholdFloat%SOH低告警阈值
cycleCountAlarmThresholdInteger次循环次数告警阈值
dataReportIntervalInteger秒数据上报间隔
heartbeatIntervalInteger秒心跳上报间隔

示例

{
  "cmdId": "cmd-20260918-config-001",
  "action": "config",
  "params": {
    "configs": {
      "cellOverVoltageThreshold": 3650,
      "cellUnderVoltageThreshold": 2500,
      "batteryHighTempThreshold": 55.0,
      "socLowAlarmThreshold": 20.0,
      "dataReportInterval": 30,
      "heartbeatInterval": 60
    }
  },
  "timestamp": "2026-09-18T10:00:00Z"
}

6.7 OTA升级指令 下行

Topic：bms/device/{imei}/cmd/ota  |  QoS：2

平台下发OTA升级指令，设备收到后下载固件并执行升级。

指令参数

字段类型必填说明
cmdIdString是指令唯一ID
actionString是固定值：ota
params.taskIdString是升级任务ID
params.firmwareUrlString是固件下载URL（HTTPS）
params.firmwareVersionString是目标固件版本号
params.firmwareSizeInteger是固件大小（字节）
params.firmwareMd5String是固件MD5校验值
params.upgradeModeString否升级模式：immediate（立即）/ scheduled（定时），默认immediate
params.scheduledTimeString否定时升级执行时间（upgradeMode=scheduled时必填）
timestampString是下发时间
timeoutInteger否超时时间（秒），默认1800（30分钟）

示例

{
  "cmdId": "cmd-20260918-ota-001",
  "action": "ota",
  "params": {
    "taskId": "ota-20260918-001",
    "firmwareUrl": "https://ota.bms-system.com/firmware/ZLB005D_V2.3.1.bin",
    "firmwareVersion": "V2.3.1",
    "firmwareSize": 2570480,
    "firmwareMd5": "a1b2c3d4e5f67890abcdef1234567890",
    "upgradeMode": "immediate"
  },
  "timestamp": "2026-09-18T09:00:00Z",
  "timeout": 1800
}

6.8 同步数据请求 下行

Topic：bms/device/{imei}/cmd/sync  |  QoS：1

平台请求设备立即上报一次完整的实时数据（电池数据+开关状态+电压信息）。

指令参数

字段类型必填说明
cmdIdString是指令唯一ID
actionString是固定值：sync
params.dataTypesString[]否请求的数据类型：data/switch/voltage/gps，不填则全部同步
timestampString是下发时间

示例

{
  "cmdId": "cmd-20260918-sync-001",
  "action": "sync",
  "params": {
    "dataTypes": ["data", "switch", "voltage"]
  },
  "timestamp": "2026-09-18T10:00:00Z"
}
设备收到同步请求后，应在5秒内分别向 bms/device/{imei}/data、bms/device/{imei}/switch、bms/device/{imei}/voltage 发送一次最新数据，并在 resp 上返回确认。

32位整数，各bit位含义：

Bit位说明1=触发
bit0充电过压保护触发充电过压保护
bit1放电低压保护触发放电低压保护

bit6电池低温保护触发低温保护
bit7MOS高温保护触发MOS高温保护
bit8充电机高温保护触发充电机高温保护
bit9SOC极低保护触发SOC极低保护

10. 附录

10.1 数据类型与单位说明

类型说明

Double64位浮点数，用于经纬度

10.2 时间格式

所有时间字段统一使用ISO 8601格式：yyyy-MM-ddTHH:mm:ssZ

时区：UTC（设备端使用UTC时间上报，平台端转换为本地时区+8展示）

示例：2026-09-18T08:30:00Z

10.3 消息去重

每个消息携带 msgId（UUID格式），平台端维护最近5分钟的消息ID缓存，重复 msgId 的消息将被丢弃。

10.4 消息大小限制

单条MQTT消息Payload不超过 16KB。单体电压数据如串数超过48串，需拆分多条消息上报。

10.5 连接重试策略

重试次数等待时间说明
第1次5秒立即重连
第2次10秒-
第3次30秒-
第4次60秒-
第5次及以后300秒持续重试，直到连接成功
